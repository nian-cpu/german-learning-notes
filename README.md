# 🇩🇪 German Learning Resources

> 德语学习资料与笔记整理｜German learning resources & notes

这是一个用于整理和分享德语学习资源的仓库。

主要收集和整理 **德语词汇、写作、听力、阅读以及 B1–B2 阶段的学习内容**，方便日常学习、复习和快速查找。

希望这些整理也能给其他正在学习德语的人提供一些帮助。🇩🇪

如果你觉得这个仓库有用，欢迎 ⭐ Star。
