## 内容原则

- 个人原创或有权公开的笔记优先使用 Markdown，便于搜索和复习。
- 第三方学习资料优先提供官方网站或原始来源链接。
- 不重新分发商业教材、完整电子书、完整考试材料、第三方题库或来源不明的文件。
- 不通过格式转换重新发布受版权保护的内容。
